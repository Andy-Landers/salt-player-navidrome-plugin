

# Plugin de Navidrome para Salt Player for Windows

## Introducción
Es un plugin para Navidrome (o quizás para todos los servidores que soportan la API de Subsonic) adaptado para Salt Player for Windows. 
Puedes transmitir música en SPW a través del plugin y aprovechar las funciones de Navidrome y Salt Player for Windows.

Este plugin permite conectar Salt Player for Windows con Navidrome (¿quizás funcione con todos los servidores multimedia que soportan la API de Subsonic?).
A través de este plugin, puedes reproducir música desde Navidrome en SPW, gestionar tu biblioteca multimedia y utilizar todas las funciones de Navidrome.
